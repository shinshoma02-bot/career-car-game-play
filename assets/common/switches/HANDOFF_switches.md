# スイッチ素材 → 開発実装部への引き継ぎメモ

作成: グラフィック制作チャット / 素材: `assets/common/switches/`(トレーラー共通・透明PNG・全63枚)
素材の絵は触らない。差し替えや追加が必要なら、グラフィック制作チャットに依頼する。

## 1. 素材の使い方

- 本体(`sw_*` / `lamp_panel*`)には**穴だけ**が描いてある。ボタン・ランプは別素材を `switches.json` の `slots`(素材内の中心座標)に重ねる。
- 押す → `_pressed` に差し替え。ランプの点灯/消灯 → `lamp_*` と `lamp_*_off` に差し替え。
- `slots` と `size` は `switches.json` に全部ある(本体の左上が原点。キャップは `pivot` が中心)。
- 取付板・柱は含まない。斜め設置は本体ごと回転して置く。大きさは実物より拡大(見やすさ優先)。

## 4. 実車のロック機構(ゲームのルール化)※ユーザーからの説明

- 走行中にタイヤ(車軸)が勝手に突出しないよう、左右それぞれにロックがある。
- **実車では、ロックを解除していないとタイヤの突出・格納ができない**(伸/縮ボタンを押しても動かない)。
- 突出・格納の手順(写真の貼り紙より): 突出 = ①ジャッキ伸 ②車軸右解除 ③車軸左解除 ④車軸突出 ⑤ジャッキ縮。格納 = ①ジャッキ伸 → 車軸格納 …(続きは貼り紙のとおり。ジャッキ = アウトリガー)。
- 今回の仕様に入れるのは「タイヤ突出/格納」と「左右ロック/解除」。左右のロックが両方「解除」でないと、伸/縮は効かない扱いにするのが実車どおり。

### ランプとの対応(提案)

| ランプ(lamp_panel_lock) | 点灯の意味 | 素材 |
|---|---|---|
| 上「作業」 | 作業可能状態(写真では消灯・赤系)。条件は実装側で決める | `lamp_red` / `lamp_red_off` |
| 中「右ロック」 | 右がロック中 | 点灯 `lamp_green` / 消灯 `lamp_green_off` |
| 下「左ロック」 | 左がロック中 | 同上 |

写真では「右ロック」「左ロック」とも緑が点灯していた(= ロック中。走行状態)。
**ロックの点灯/消灯が逆の意味になっていたら、素材は変えず実装側で差し替えを反転すればよい。**
